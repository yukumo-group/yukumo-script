Yukumo-Script is an application that generates Yukumo audios using AquesTalk2. It can generate audios in the following ways: 
- Generate audio from a single sentence with the phont name. 
- Generate audio from a single sentence with predefined characters. 
- Generate audio/subtitle file from scripts. 

You can visit code repo here: 
[Repo](https://github.com/yukumo-group/yukumo-script)
